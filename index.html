🌡️ Système IoT de Surveillance de Température (Edge + Cloud)

Projet IoT intelligent basé sur l'ESP32 permettant la surveillance en temps réel de la température via une architecture Edge + Cloud. Le système collecte les données grâce à des capteurs connectés, les traite localement sur l'ESP32 puis les envoie vers le cloud pour le suivi et le stockage. Le projet intègre également une interface web embarquée permettant de visualiser les données en direct, surveiller l'état du système et recevoir des alertes en cas de dépassement de seuil critique. 🔧 Technologies utilisées : ESP32, IoT, interface web embarquée, communication réseau, Edge Computing, Cloud Computing.
